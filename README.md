# rixle_website

Production source code for Rixle Ecosol (rixle.co.in).

## Deployment & Hosting Compatibility
- **GitHub Pages**: Static deployment configured via `.github/workflows/deploy.yml` with custom domain routing (`CNAME`) and `.nojekyll` bypass.
- **Cloudflare Pages**: Fully compatible zero-config deployment. Root assets, script modules, and fallback placeholders are verified.
